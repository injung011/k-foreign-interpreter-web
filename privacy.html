통역 자막 — 개인정보 안내

이 웹앱은 별도의 서버에 사용자의 대화나 개인정보를 저장하지 않습니다(현재 버전 기준).

1. 전송되는 정보

  • 무료 모드: 마이크 소리는 브라우저(크롬)의 음성 인식 서비스(Google)로, 인식된 글은 Google 번역으로 전송됩니다.
  • 내 OpenAI 키 모드: 말한 부분의 소리와 인식된 글이 사용자의 키로 OpenAI에 전송됩니다. 요금은 키 주인의 OpenAI 계정에서 나갑니다.
  • 각 서비스의 개인정보 처리는 해당 회사의 정책을 따릅니다.

2. 이 기기에만 저장되는 정보

  • 설정, OpenAI API 키, 최근 통역 기록(최대 500건), 대략적인 사용 금액은 이 기기 브라우저 저장소에만 저장됩니다.
  • 설정 → 통역 기록 → 기록 지우기, 설정 → 키 삭제로 언제든 지울 수 있습니다. 브라우저의 사이트 데이터 삭제로도 모두 지워집니다.

3. 사용 시 주의

  • 대화 상대에게 통역 앱 사용과 외부 서비스 전송 사실을 미리 알려 주세요.
  • 의료·법률 등 중요한 상황에서 AI 통역은 틀릴 수 있으니 전문가 확인을 받으세요.
  • 여러 사람이 쓰는 기기에는 API 키를 저장하지 마세요.
