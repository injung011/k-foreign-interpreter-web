AI 연결 방식

키 만드는 방법 (5분)
  1. platform.openai.com에 가입·로그인 (ChatGPT 계정 그대로 가능)
  2. Settings → Billing에서 카드 등록 후 $5 충전. 자동 충전(Auto recharge)은 끄기를 권장 — 충전한 금액 이상은 나가지 않습니다.
  3. API keys → Create new secret key → 만들어진 키(sk-…) 복사
  4. 위 칸에 붙여 넣고 연결 시험 → 저장

참고 요금: 실제로 말한 시간 1시간에 약 $0.3(인식+통역), 소리로 읽기는 1시간 읽기에 약 $0.9. ChatGPT 구독과는 별개입니다.

⚠ 키는 이 기기의 이 브라우저에만 저장됩니다. 여러 사람이 쓰는 기기에는 넣지 마세요.
