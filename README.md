# 통역 자막 (웹)

두 언어로 하는 말을 받아 적고 AI로 통역해 화면에 나란히 보여 주는 웹앱입니다.
휴대폰·태블릿·노트북의 크롬에서 주소만 열면 동작하고, **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.

## 쓰는 방법
1. 위에서 두 언어(15개 언어 중)와 **상황**(교회·병원·회의·일상·여행, 한 줄 설명)을 고릅니다.
2. **▶ 통역 시작** → 언어마다 창이 따로 있습니다(휴대폰은 위·아래, 넓은 화면은 좌·우). 각 창에 그 언어로 된 **원문**과 **AI 통역**이 나옵니다.
3. 창 머리의 🔈 = 그 언어 통역을 소리로 읽기, ⤢ = 그 창만 화면 가득(다시 누르거나 '둘 다 보기'로 복귀).
4. 📡 **보기 전용 공유**: 주소·QR을 받은 사람은 자막만 봅니다(설정·마이크·키 접근 불가). 글자 크기·한 창 보기는 보는 사람이 각자 조절.
   - 다른 기기끼리 공유하려면 `js/config.js`에 Supabase 주소와 공개(anon/publishable) 키를 넣어야 합니다. **service_role 키는 절대 넣지 마세요.**
   - 설정 전에는 같은 기기의 다른 창(예: 빔프로젝터용 창)에서만 보입니다.
5. ⚙ 설정: 화면 언어(한국어·Русский·English), 연결 방식, OpenAI 키(📋 붙여넣기 버튼), 이름·용어 힌트, 목소리, 마이크, 글자 크기, 창 배치, 윗창 뒤집기(마주 앉은 대화), 기록.

## 📜 대본 모드 (설교 대본이 있을 때)
1. 한국어 대본을 구간으로 나누고 러시아어를 짝지은 txt 파일을 준비합니다(형식은 아래, 다른 AI 창에 맡겨도 됨).
2. 📜 → 대본 파일 고르기 → 자동으로 대본 모드가 켜집니다. 말하는 언어는 **한국어**로 고정하면 더 안정적입니다.
3. 말씀을 들으며 대본의 지금 위치를 따라갑니다: 지나간 구간은 옅게, **지금 구간은 굵게**, 다음 구간은 보통 글씨.
   대본에 있는 말은 번역을 기다리지 않고 준비된 러시아어를 바로 보여 줍니다(번역 요금도 없음).
4. 대본에 없는 말은 그 자리에 **파란 글씨**로 끼워 넣고 AI가 통역합니다(대본 끝의 용어표를 따름).
5. 위치가 어긋나면 구간을 누르거나 ↑↓ 키로 바로잡습니다. 새로고침해도 위치가 이어집니다.
6. 📡 공유 중이면 보는 사람 화면도 같은 대본으로 따라갑니다(대본은 공유를 연 동안 보는 사람에게 전송됨).

```
[1]
KO: 2. 구속과 위로의 하나님
RU: 2. Бог искупления и утешения

[2]
KO: 한국어 구간(1~2문장)
RU: 러시아어 구간

용어표
하나님 = Бог
```

## 연결 방식
| 방식 | 요금 | 특징 |
|---|---|---|
| 무료 모드 | 없음 | 크롬 내장 음성 인식 + 무료 번역. 말하는 언어를 직접 골라야 함 |
| 내 OpenAI 키 | 키 주인의 OpenAI 계정 | 자동 언어 감지, 높은 정확도, 상황별 통역(gpt-transcribe + 번역 모델) |
| Google Gemini 키 | 무료 구간(결제 미등록 시 요금 없음) | 받아 적기+번역을 한 번의 요청으로(분당 한도 절약), 자동 언어 감지. 분당·하루 한도, 무료 구간 내용은 구글 개선에 쓰일 수 있음. 읽기는 기기 목소리 |
| 회원 로그인 | 관리자 | 준비 중 (관리자 승인 회원만, 서버에서 키 보관) |

키(OpenAI·Gemini 각각)는 사용자의 브라우저에만 저장되고, 이 저장소나 다른 서버로 보내지지 않습니다(OpenAI·Google로 직접 호출).

## 개발
정적 파일만으로 동작합니다(빌드 단계 없음). GitHub Pages로 배포합니다.

```
node --test tests/*.test.js                 # 핵심 로직 단위 시험
python3 tests/script_test.py /tmp/out2       # 대본 모드(가짜 인식 결과로 위치 따라가기·파란 글씨·공유)
python3 tests/gemini_test.py /tmp/out4       # Gemini 연결(가짜 서버: 틀린 키, 분당 한도, 모델 없음, 자동 언어)
python3 tests/stress_test.py /tmp/out3       # 빠르게 쉬지 않고 75초 말하기 + 느리고 가끔 실패하는 서버 → 놓치는 말이 없는지
python3 tests/browser_test.py /tmp/out       # 실제 크롬 + 가짜 마이크 + 가짜 OpenAI 서버로 전체 흐름 시험
python3 -m http.server 8000                  # 로컬 실행 → http://127.0.0.1:8000
```

- `js/engine.js` 통역 흐름 · `js/segmenter.js` 문장 나누기 · `js/openai.js` OpenAI 호출
- `js/i18n.js` 화면 언어 · `js/share.js` 보기 전용 공유 · `js/config.js` Supabase 공개 설정
- `js/free.js` 무료 모드 · `js/tts.js` 소리로 읽기 · `js/situations.js` 상황별 지시
- 시험용 가짜 서버 주소(`?apiBase=`)는 이 컴퓨터(localhost)에서 열었을 때만 적용됩니다.

PC(Windows) 버전: [k-foreign-interpreter](https://github.com/injung011/k-foreign-interpreter)
